# Tachyon

Tachyon: Theoretical particle that always goes faster than light, no experiments have shown that it exists...

This is a kernel, It has basic features like printing text to the screen and consuming electricity, I promise I will add more features when I have time.

(Note: this project was made by only person which is why the code might look bad, you can help me fix this by contributing)

This project will probably not be useful for many people, it is made entirely as a learning project to receive feedback and experience on programming.


Requirements to build:

  - GCC and Binutils
  - NASM installed

Requirements to run:
  - 32 bits
  - at least 10MB of RAM
  - electricity
